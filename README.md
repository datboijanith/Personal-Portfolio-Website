# Personal Portfolio Website

A modern, interactive personal portfolio website designed to showcase my skills, projects, technical growth, and professional identity as an IT undergraduate and aspiring software developer.

This project is built with the goal of creating more than just a simple personal website. It is intended to be a polished digital profile that reflects creativity, attention to detail, technical curiosity, and a strong interest in modern web development.

## About This Project

This portfolio website is being developed as a professional online presence where I can present my work, share my development journey, and demonstrate my ability to build clean, responsive, and visually engaging web experiences.

The design direction is inspired by modern product websites that use bold typography, smooth scrolling, strong visual sections, interactive layouts, and high-quality presentation. The goal is to create a portfolio that feels professional, memorable, and technically impressive.

## Purpose

The main purpose of this project is to:

- Showcase my personal projects and technical skills
- Present my background as an IT enthusiast and software development learner
- Build a strong professional identity online
- Demonstrate frontend development, UI design, and animation skills
- Create a portfolio that can be shared with recruiters, lecturers, clients, and collaborators

## Planned Features

- Modern responsive design

- About me section

- Contact section
